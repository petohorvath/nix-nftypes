# Triage labels

Skills refer to triage roles. Apply the matching label from this table.

| Role              | Label             | Meaning                                      |
| ----------------- | ----------------- | -------------------------------------------- |
| `needs-triage`    | `needs-triage`    | A maintainer needs to evaluate it            |
| `needs-info`      | `needs-info`      | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an AFK agent   |
| `ready-for-human` | `ready-for-human` | Needs a human to implement it                |
| `wontfix`         | `wontfix`         | Won't be actioned                            |

`wontfix` already exists on GitHub. `/triage` creates the other four the first time it uses them.
